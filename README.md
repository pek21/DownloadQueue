# Вариант 13. Очередь загрузки ресурсов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Task, async I/O, SemaphoreSlim, Channel, Process

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать модель задания загрузки с URL и статусом.
2. Реализовать асинхронное сохранение локального файла из предоставленного тестового источника/потока.
3. Ограничить число одновременных загрузок.
4. Организовать producer-consumer очередь через Channel.
5. Собирать результат и ошибку каждого задания.
6. Добавить журнал времени начала и окончания.
7. Сохранять каталог загрузки в HKCU.

## Дополнительные задания
8. Добавить повторную постановку задания после временной ошибки с ограничением попыток.
9. Сформировать итоговую статистику через LINQ.
10. Добавить запуск папки результата через Process.Start с проверкой платформы.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
